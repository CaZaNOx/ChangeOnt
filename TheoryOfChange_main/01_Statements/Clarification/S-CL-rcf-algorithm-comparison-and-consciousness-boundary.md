# RCF comparison and consciousness boundary

## Minimum RCF distinction

RCF is not distinct merely because it has branches, uncertainty, message passing, or delayed commitment. The minimal distinction criterion is:

```text
holding scalar candidate fields fixed,
changing relation topology, burden operations, quotient status, or collapse blockers
must change field/certificate/readout behavior for traceable structural reasons.
```

If RCF cannot pass that criterion, it is not a CO-native continuation-field mechanism. It is scalar scoring or known planning/search machinery with CO vocabulary.

## Known-algorithm comparison obligation

Before any novelty claim, RCF must be compared to:

```text
MCTS / tree search;
dynamic programming;
belief propagation / message passing;
active inference;
options / temporally extended action;
successor representations;
state abstraction;
heuristic search;
constraint satisfaction / graph search.
```

The comparison must state what RCF shares, what it reinterprets, and what, if anything, is algorithmically distinct. It is acceptable if the final novelty is architectural/philosophical rather than a wholly new algorithm, but the claim must be honest.

## Consciousness boundary

The current kernel work does not prove consciousness, AI consciousness, or felt subjectivity. The safe bridge is:

```text
meaning-like relevance = retained difference that changes continuation burden, salience, admissibility, or collapse-readiness.
```

This is a possible route toward a later CO account of meaning and consciousness, but it is not yet a theory of felt subjectivity. Open later issues include:

```text
subject-pole formation;
felt relevance vs functional relevance;
self-world integration;
graded proto-conscious standing;
ethical thresholds;
AI self-report and simulation-vs-modulation tests.
```

The current kernel may serve as an operational analogue or precursor. It must not be presented as a completed consciousness theory.
