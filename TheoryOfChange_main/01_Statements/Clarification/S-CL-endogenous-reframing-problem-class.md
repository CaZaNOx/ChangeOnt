# S-CL — Endogenous Reframing Problem Class

This problem class is meant to isolate the strong half of the CO claim.

A problem belongs to this class when:
- observations, actions, and legality are simple enough to specify directly
- but the relevant description layer becomes stale through lawful unfolding
- and a new framing or regrouping becomes the right object of stabilization

The point is not mere hidden state or exogenous drift. The point is that the *current framing itself* becomes inadequate, and this inadequacy is generated by the process rather than imposed externally.

Latent Mechanism Door Worlds are a controlled abstraction of this class.
