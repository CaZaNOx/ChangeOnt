Goal:
- begin from change/happening justified as primitive;
- derive the earliest world-forming constraints without smuggling static substances;
- clarify how local reshaping carries forward through **shape-sensitive continuation**: continuation occurs through local shape rather than beside it, so some formed differences matter more than others and can later matter again;
