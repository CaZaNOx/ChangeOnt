# New problems must be placed by one fixed public six-question shape protocol

## Content

A new problem must not be hand-placed by family intuition, hidden policy, or after-the-fact performance. Placement closure requires one fixed public protocol:

```text
public problem contract
→ six-question shape prior
→ direct runtime controls / gauge settings
→ kernel unfolding
```

## Admitted problem contract

Every problem submitted to the protocol must provide, in parity-honest public form:

```text
what is currently observed;
what actions are legal or admissible;
what transition grammar is public;
what counts as success, failure, or task continuation;
whether rules and anchors are fixed, reactive, or shifting;
what information is hidden but potentially revealable;
what information is forbidden to the agent.
```

If a problem cannot be expressed in this contract, it is outside the current kernel-validation envelope or requires explicit contract extension before evaluation.

## Six-question placement protocol

The active public questions are:

```text
hidden_decisiveness;
reshapeability;
local_cue_reliability;
revision_cost;
consequence_span;
topology_constraint.
```

Each axis must be assigned from public problem facts, declared task structure, or visible stream evidence available to parity-honest baselines. The mapping must be frozen before evidence runs or labeled exploratory.

## Forbidden placement sources

Placement may not use:

```text
benchmark labels as a shortcut;
after-the-fact winner identity;
hidden state unavailable to the agent;
solver value estimates;
family-local tuning rules;
observed performance from trial runs.
```

## Readout consequence

A lawful placement protocol is still incomplete if action selection is hidden inside adapter-authored or candidate-surface-local ranking logic. The boundary exposes public facts; the kernel derives continuation identity, burden operations, relations, field state, and earned collapse.
