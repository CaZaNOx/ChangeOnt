# First-layer canonical path

This file gives the **current canonical human reading order** for the first layer.
It is not the full graph and it is not the whole archive. It is the shortest disciplined route through the material that currently justifies change as primitive and then develops the first consequences of taking change as ontologically primary.

## What “first layer” includes
First layer includes **both**:
- the opening justification for why change is the strongest primitive against rival starts; and
- the first ontological development that follows once change is taken as primitive.

So first layer is not only “why start with change?” and it is not yet the whole later ontology. It is the justified start **plus** the first build from that start.

## Shared opening
1. `01_Statements/00_Opening_Justification/`
2. `01_Statements/01_Change_Clarification/`

These secure:
- what critical reading cannot responsibly discard,
- why change is the strongest primitive against rival starts,
- that the opening datum is already processive happening rather than bare eventhood,
- that global change is not originable from a changeless base and is best read as globally non-ceasing even though only local regimes may stabilize,
- and that genuine happening remains in principle refinable rather than terminating in a final opaque eventlet.

## Reader rule
If you want the shortest disciplined first-layer path, first read the route `README.md` files in the order above, then read every numbered file inside each active route directory in the order stated by that route README. Do not rely on raw filename sorting when a suffix file depends on an underscore-numbered file; for example, `022_S-DF-thin-collapse-law.md` must be read before `022A_S-DR-shape-space-directed-unfolding-from-change.md`. Reading only the route README files is not enough for a conceptual audit.
Use `02_Concepts/` for topic-level recomposition and `03_Derivation/graph_first_layer.mmd` for the filtered dependency view.

## Freeze rule
Do not silently expand first layer merely because a later continuation can be made smoother.
If a later step is helpful but not clearly required for first-layer closure, preserve it **after** the first-layer boundary rather than moving the boundary outward.
