# Contrast within now — present happening is not self-exhaustively flat

## Claim
The immediate datum is not an undifferentiated point. Present happening contains internal articulation or contrast: it is not self-exhaustively flat.

## Why this file exists
The route cannot move toward any weak beyondness if the present is treated as a featureless point. This file therefore secures only the thinnest needed result: present happening is internally articulated enough that it is not exhausted by a flat now.

## Argument
1. The immediate datum was not secured as bare abstract existence, but as occurring/non-flat givenness.
2. If the present were completely flat, there would be no internal differentiation by virtue of which it could appear as happening rather than as a featureless point.
3. But the opening has already secured happening/modulation rather than featureless presence.
4. Therefore present happening includes internal contrast.
5. A present with internal contrast is not self-exhaustively flat.

## Why this does **not** yet yield prior
This file does not yet derive predecessor, time, or reach. It only blocks the flat-point reading of the present. Any stronger move must be argued separately.

## Objections and replies
### Objection 1: “Couldn’t happening still be point-like?”
Only at the cost of evacuating the very non-flatness by which happening was secured. A featureless point does not carry modulation.

### Objection 2: “Is contrast already difference-between-things?”
No. It is only internal articulation within present happening, not yet contrast between pre-given objects or states.

## What this file establishes
- present happening is internally articulated,
- and therefore not self-exhaustively flat.

## What this file does not yet establish
- prior,
- reach,
- time,
- or space.

## Remaining criticism
### Conceptual gap
The main conceptual question is whether “happening” already guarantees internal articulation, or whether a critic can still insist on a point-like but occurring present. The file is plausible, but the burden remains to show that a featureless occurrence is unstable rather than merely unfamiliar.

### Formulation gap
“Contrast” may still sound stronger than what is secured. The real claim is only internal articulation or non-flatness, not yet comparison between objects, states, or explicit relata.
