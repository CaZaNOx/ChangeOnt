# Canonical Problem Definition and Placement Basis

## Canonical claim in this clean snapshot

A problem is given to the system in two layers:
1. a **public lawful problem specification**;
2. a **generic six-question shape prior** that approximates the stabilized regime/context of change the kernel is operating in.

The translator publishes the first layer. The placement layer derives the second layer from the first.

## Canonical chain

`public problem contract -> six-question shape prior -> environment basis -> direct controls -> kernel`

The six-question prior is a coarse regime/context prior, not the whole problem.
