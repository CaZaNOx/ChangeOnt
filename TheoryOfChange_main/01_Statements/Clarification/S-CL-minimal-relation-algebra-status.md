# Minimal relation algebra status

## Thesis

Branch relations must not be arbitrary labels. They are derived from how one continuation-pressure signature changes another continuation-pressure signature.

The active named relations are readable derived cases:

```text
relief;
cancellation;
exposure / shared evidence;
rivalry;
dependency;
proximity;
quotient/equivalence;
weak decision-slot competition.
```

But these names are not yet proven to be the minimal algebraic basis.

## Deeper coupling basis

The target state is to derive named relations from a smaller set of couplings:

```text
burden coupling:
  one branch changes the burden carried by another;

admissibility coupling:
  one branch changes whether another remains live or allowed;

evidence/visibility coupling:
  one branch exposes, hides, or changes evidence relevant to another;

identity coupling:
  one branch changes whether another preserves its continuation identity;

collapse coupling:
  one branch changes whether another may quotient, recurse, remain grey, or collapse.
```

Named relations are then interpretations of these couplings:

```text
relief = burden coupling that lowers same-type operative burden;
cancellation = admissibility/condition coupling that removes a burden-bearing condition;
exposure = evidence coupling that makes hidden burden available;
rivalry = admissibility coupling where continuations cannot remain live together;
dependency = admissibility/evidence coupling where one branch relies on another;
proximity = any coupling strong enough to change another branch's status;
quotient = identity/collapse coupling where differences no longer matter;
weak decision-slot competition = procedural readout competition, not structural rivalry.
```

## Target-state rule

RelationSurface may output named relation types, but the reason trace must identify the underlying coupling and public basis. A relation without public basis or coupling explanation is not evidence-bearing.

## Open formal watchpoint

The current relation system is good enough for target-state docs and diagnostics, but not a completed algebra. Remaining work:

```text
prove whether the coupling basis is sufficient;
show which named relations are primitive or reducible;
handle multi-relation conflicts;
formalize operation composition and monotonicity/non-monotonicity;
define false-positive and false-negative relation tests.
```
