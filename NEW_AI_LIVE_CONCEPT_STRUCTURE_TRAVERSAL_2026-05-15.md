## 3. Current architecture understood

The current executable target is:

```text
Boundary / Adapter
→ CandidateSurface
→ Continuation Identity
→ Burden Operations
→ RelationSurface
→ RecursiveContinuationField
→ CollapseCertificate
→ CommitmentSurface
```

Layer meaning:

```text
Boundary / Adapter:
  publishes lawful public observations, legal candidates, public_effects, and public constraints.
  It must not solve, leak hidden policy, rank by optimality, or publish relation conclusions.

CandidateSurface:
  publishes candidate rows as intake carriers, not final branches or final decisions.

Continuation Identity:
  branch identity uses continuation_id → branch_id → candidate_id → action.
  Action is only last-resort interface identity.

Burden Operations:
  branch-internal operations such as carry, expose, mask, buffer, relieve, cancel, transform, threshold must survive even without cross-branch relation.

RelationSurface:
  derives typed branch relations kernel-side from public burden/effect facts.
  It must separate weak decision-slot competition from strong rivalry.

RecursiveContinuationField:
  updates field_debt, relief support, grey pressure, recursion demand/budget, quotient markers, collapse readiness, and field viability.

CollapseCertificate:
  checks whether collapse is earned and preserves structured reasons/blockers.

CommitmentSurface:
  final readout. It must respect certificate gates and fail closed rather than rescue with first-legal, uniform, greedy, baseline, or score-only fallback.
```
