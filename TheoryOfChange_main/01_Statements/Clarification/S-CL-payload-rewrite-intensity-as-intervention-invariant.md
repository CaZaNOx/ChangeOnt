# Payload Rewrite Intensity should be measured as a shared intervention-response invariant
## Content
Payload Rewrite Intensity should not be assigned by family intuition or retrospective fitting. It should be measured by a shared intervention-response rule that applies across all admitted problems.

The shared question is:

> How rapidly content attached to a relatively stable scaffold becomes stale or needs replacement.

## Why this form is needed
If payload rewrite intensity is left as an impressionistic label, then cross-problem placement remains handwavy. The same number on the vector would not mean the same thing across maze, bandit, renewal, games, search, or control.

## Shared measurement idea
A lawful placement should expose whether payload assignments on recurring carriers change frequently. The score should therefore come from carrier-payload persistence probes.

## Dimensionless readout
A suitable dimensionless readout is: normalized payload change rate conditional on scaffold persistence.

What must remain invariant is not the raw unit but the logic:

> stronger expression of the same intervention-response pattern means a more extreme value on the vector.

## Directional law
If a problem deformation changes the task so that the same probe exhibits stronger expression of this pattern, then the vector should move monotonically in the corresponding direction.

## Placement consequence
Higher values should weaken content-level carry-forward and increase revision pressure.

## Misuse warning
It is invalid to assign payload rewrite intensity by family label or by whichever environment later performs best. The score must come from the shared intervention-response rule itself.
