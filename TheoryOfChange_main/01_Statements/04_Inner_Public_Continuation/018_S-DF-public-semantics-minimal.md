# Public semantics minimal — symbol-bearing carriers begin to guide reuse under weakly shared rule-like expectations
## Claim (formal)
Public semantics minimal arises when symbol-bearing carriers are not only recurrent and publicly revisitable, but also begin to guide uptake and reuse under weakly shared expectations about what counts as carrying the same distinction and when that carriage misfires.

## Philosophical Translation (of formal claim)
A repeated public symbol is still not enough for even a weak public semantics. Something more is needed: participants must begin to expect that the symbol should be reused in certain ways and not in others. This is the first minimal public semantic layer.

## Philosophical Justification
Symbol-bearing structure minimal secures recurrent public carriers that preserve the same distinction across tokens. Shared gauge minimal secures repeated calibration across multiple holds. But if there is no weakly shared expectation about how those carriers should guide reuse, then the structure remains a repeated mark system with no stronger public meaning. Public semantics minimal begins when recurrent symbol-bearing carriers are taken up under a weakly shared rule-like expectation: some uses count as preserving the same distinction, while some uses count as drift, corruption, or misfit. This remains much weaker than full language, grammar, or explicit norm systems, but it is stronger than mere repeated symbol-bearing.

This file matters because the first layer should not leap from symbol-bearing recurrence directly to rich language or social institutions. The first public semantic threshold is weaker: recurrent symbol-bearers begin to carry expectations of right-enough reuse.

## Explanation (informal)
A public symbol system becomes minimally semantic when its carriers are not only repeated, but reused under shared expectations about what they are supposed to keep carrying.

## Derivation (Philosophical)
- Symbol-bearing structure minimal secures recurrent public carriers of the same distinction.
- Shared gauge minimal secures repeated calibration across holds.
- Stronger public meaning requires that reuse not remain arbitrary from one token to the next.
- Therefore public semantics minimal arises when symbol-bearing reuse is weakly constrained by shared expectations of preserving the same distinction.

## Derivation (Formal/Logical/Mathematical)
```text
Let c be a symbol-bearing carrier-type for distinction d across holds H1...Hn.
PublicSemantics_min(c,d) iff:
(1) SymbolBearing_min(c,d) holds,
(2) SharedGauge_min(H1...Hn,d) holds,
(3) participants weakly expect some reuses of c to preserve d better than others,
(4) some reuses are now treated as better fits and some as misfires relative to d.
```

## Proofs/Corollaries References
- successor: richer intersubjective gauge and later language-like structure can build on public semantics minimal rather than bypass it.

## Clarifications / Further Context
- This is not yet full language, explicit grammar, or institutionally enforced meaning.
- "Rule-like" here is minimal: expectations of better/worse reuse, not formal codification.
- The point is the first public semantic constraint on symbol-bearing recurrence.

- later ask how weak public semantics feeds back into inner semantic loading and self-model evolution.
