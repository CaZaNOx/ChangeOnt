# Symbol-bearing structure minimal — recurrent public carriers preserve the same distinction across multiple tokens
## Claim (formal)
Symbol-bearing structure minimal arises when a public carrier can recur in multiple tokens while preserving enough invariant significance that those tokens continue to bear the same distinction rather than merely repeating a similar mark.

## Philosophical Translation (of formal claim)
A public mark is not yet a symbol just because it persists. The minimal symbol threshold begins when multiple occurrences of that public carrier still count as carrying the same distinction. The repeated mark is now not merely there again; it bears the same guide again.

## Philosophical Justification
Public stabilization minimal has already secured durable common marks. But a durable mark may still remain tied to one local context or one unrepeatable event. For symbol-bearing structure, recurrence must preserve the same distinction across multiple tokens. Stabilized same-type guidance already secures same-type guidance inwardly; public stabilization secures durable outward availability. Symbol-bearing structure minimal arises when these two lines meet: repeated public tokens carry the same distinction strongly enough to function as one bearer-type rather than many unrelated occurrences.

This is still weaker than full language, syntax, or normative semantic systems. The point is only that recurrent public carriers now stably bear a distinction across multiple tokens.

## Explanation (informal)
A durable public mark becomes minimally symbol-bearing when repeated tokens of it continue to carry the same distinction rather than just looking similar.

## Derivation (Philosophical)
- Public stabilization secures durable common marks across multiple holds.
- Stabilized same-type guidance secures inward same-type guidance across multiple occurrences.
- When recurrent public tokens preserve that same distinction across more than one token, the public carrier becomes minimally symbol-bearing.
- Therefore symbol-bearing structure minimal is the first threshold where repeated public tokens bear the same distinction.

## Derivation (Formal/Logical/Mathematical)
```text
Let c be a public carrier-type with tokens c1...cn bearing distinction d.
SymbolBearing_min(c,d) iff:
(1) PublicStabilization_min(d) holds,
(2) multiple tokens of c recur,
(3) recurrence preserves enough invariant significance of d,
(4) those tokens can be taken as bearing the same distinction d across reuse.
```

## Proofs/Corollaries References
- successor: richer public semantics requires not just repeated symbol-bearing carriers, but a more stable shared rule for how such carriers guide uptake and reuse.

## Clarifications / Further Context
- This is not yet a full theory of language, syntax, or public normativity.
- A symbol-bearing structure can be primitive, local, and partial.
- The point is bearer-type continuity across tokens, not advanced semantics.

## Next Steps in Chain
- derive public semantics minimal as the first threshold where symbol-bearing carriers guide reuse under a weakly shared rule;
- later relate symbol-bearing structure to richer intersubjective gauge and explicit language-like systems.
