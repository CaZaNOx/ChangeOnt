# CollapseCertificate

CollapseCertificate is the canonical surface that records whether collapse into a branch is earned. It preserves structured reasons: unresolved rivals, quotient resolution, hiddenness tolerance, burden blockers, recursion demand, and grey still operative.

It must not collapse these reasons into an undocumented score-only selector.
