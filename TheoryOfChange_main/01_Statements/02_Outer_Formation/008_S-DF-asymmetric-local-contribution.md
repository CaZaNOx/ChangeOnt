# Asymmetric local contribution — within bounded unfolding, some articulations contribute more directly than others without yet earning full prior

## Claim
If local bounded bearing is real, then within such a bounded unfolding some articulations can function as stronger contributors to the present articulation than others. The earned result is asymmetric local contribution, not yet a full outer theory of prior.

## Important caution
This file does **not** yet establish full time, global past, temporal metric, or a finished predecessor structure. The clearest first case for richer predecessor-sensitivity may still belong to the inner route. The present file secures only a weak local asymmetry of contribution.

## Argument
1. Local reach-zone restricts bearing to a bounded tracked unfolding.
2. Within such a bounded unfolding, contribution need not be symmetrical in role even when coexistence is local.
3. If every locally bearing articulation contributed in exactly the same way, the route would have no foothold for differential carry, retention, or bounded hold.
4. But overlapping unfolding already supports stronger and weaker contribution roles within a tracked local articulation.
5. The weakest honest name for that asymmetry is asymmetric local contribution.

## Why this is weaker than a real prior theory
The file does not claim a universal before/after ordering. It claims only that, inside bounded unfolding, some articulation can function as more directly contributive to another than some others do. That is a role asymmetry, not yet a global temporal doctrine.

## What this establishes
1. The route may speak of asymmetric local contribution.
2. Later bounded-hold structure has a local foothold without requiring full time-theory.
3. The outer route remains explicitly weaker than the inner route on predecessor-sensitive structure.

## What this does not yet establish
It does **not** yet establish:
- full temporal order,
- global before/after,
- or a finished philosophy of time.
