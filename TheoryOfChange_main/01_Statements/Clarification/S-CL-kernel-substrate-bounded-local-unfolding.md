# Kernel substrate as bounded local unfolding

## Content
The kernel does not operate over a smuggled ready-made world-state. Its substrate is the bounded local unfolding currently maintained by a local structure inside change. At kernel resolution this includes retained traces, active local comparisons, admissibility structure, inherited stabilized embedding, and actionable continuation options. The substrate is therefore a current local hold of unfolding, not a hidden substance beneath process.

## Implication
When code or theory speaks about the kernel "state" or "workspace", it should be read as this bounded local unfolding substrate. This prevents accidental reintroduction of a classical substrate ontology.
