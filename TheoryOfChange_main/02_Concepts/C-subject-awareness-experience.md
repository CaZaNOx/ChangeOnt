# Subject — Awareness — Experience (Minimal Triad)
Overview:
The inner route begins by decomposing and then reuniting the minimal lived triad.

- **Subject** names the minimal pole of lived givenness.
- **Awareness** names the lived openness relation.
- **Experience** names the given content/occurring.
- **Structure of experience** then makes explicit that these are three inseparable moments of one minimal lived structure.
- **Subject as recursive field** re-describes this triad as a bounded re-entering field rather than a static bearer.
- **Subject arisal ground** marks when that recursive field is supportably the same field across change.
- **Minimal memory witness** and **memory-trace integration** then show how prior trace can begin to matter for the same subject rather than leaving each breath isolated.
- **Recurrent self-related mapping**, **subject-relative loading**, **loaded distinction stabilization**, and **stabilized reusable co-treatment across variation** then show how the inner route moves from memory into reusable inner guidance without leaping straight to concepts or language; outward carriage and communication synchronization are now explicit intermediate steps.
