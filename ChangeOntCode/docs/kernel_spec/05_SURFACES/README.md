# Runtime Surfaces — Canonical

Runtime surfaces are implementation locations where kernel primitives/elements are applied. They are not deep ontology primitives.

Active surfaces:

- `CandidateSurface`: publishes evidence-bearing candidate rows.
- `RelationSurface`: derives cross-branch relations from public burden/effect facts.
- `RecursiveContinuationField`: updates branch field state.
- `CollapseCertificate`: records structured earned-collapse reasons and blockers.
- `CommitmentSurface`: expresses earned collapse as native action.
