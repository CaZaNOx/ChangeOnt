# Quotient equivalence as active continuation tolerance

## Thesis

A quotient is not a shortcut based on visual similarity, action-label sameness, scalar closeness, or value equivalence. In the ChangeOnt kernel, quotienting is the lawful thinning of live branch difference when the remaining difference no longer changes active continuation structure.

A branch pair is quotient-equivalent only when, under the current continuation anchor and gauge, their remaining differences no longer alter:

```text
1. operative burden profile;
2. admissible transformations;
3. relation topology;
4. grey-preservation need;
5. recursion demand;
6. collapse consequence;
7. readout expression.
```

This is the conceptual target state. The exact operational tolerance may be approximate, local, and empirically calibrated, but it must aim at this criterion rather than at raw score similarity.

## Why quotient follows from CO

Change produces difference. Retention preserves some difference. Collapse thins difference. Quotient is the special case where several retained differences can be treated as one for an active continuation purpose because preserving them separately would not change how continuation unfolds.

Therefore quotient is not optional bookkeeping. It is the kernel-side expression of minimal adequate retention:

```text
retain live difference while it changes continuation;
quotient difference once it no longer does.
```

Without quotienting, the kernel preserves unnecessary grey forever. With over-loose quotienting, it erases live alternatives. The target is neither maximal distinction nor premature merge, but active continuation tolerance.

## Distinction from ordinary state abstraction

Ordinary state abstraction often merges by representational similarity, value equivalence, transition similarity, or handcrafted features. CO quotienting may coincide with these in special cases, but its target is different:

```text
CO quotient equivalence = loss of continuation-relevant difference under active burden/relation/collapse conditions.
```

Two branches may be visually or action-wise different but quotient-equivalent if their remaining differences no longer alter burden, relation topology, or collapse. Conversely, two branches may have the same action label or similar scalar score and still fail quotient if one carries hiddenness, masking, unresolved rivalry, or a different barrier/threshold regime.

## Minimal quotient certificate

A quotient certificate should answer:

```text
same anchor?                    yes/no
same or compatible burden type?  yes/no
same operation class?            yes/no
same barrier/threshold regime?   yes/no
same collapse consequence?       yes/no
same relevant relations?         yes/no
same readout role?               yes/no
within active gauge tolerance?    yes/no
```

Only if the answers are sufficient under the active gauge may quotienting proceed.

## Open operational watchpoint

The concept is closed enough for docs/code target state, but the exact operational tolerance is not final. A critic may still ask how the kernel detects non-relevance without solving the whole task. The honest target-state answer is:

```text
The ideal quotient criterion is conceptual.
The runtime criterion is a local approximation using public burden/effect facts, pressure signatures, relation topology, gauge controls, and trace-tested counterexamples.
The approximation must be fixed before evidence runs and audited by false-quotient / false-separation tests.
```

## Required counterexamples

A future implementation must distinguish:

```text
same action, non-equivalent burden regime;
different action, same continuation role;
similar scalar score, different hiddenness burden;
different path, same quotient after burden resolution;
dense equivalent paths that should merge;
dense non-equivalent paths that should preserve grey.
```

Failure on these counterexamples means quotient is not yet CO-valid.
