# Acceptance Gate — Canonical

The acceptance gate checks whether code implements the canonical docs. It does not define new runtime behavior.

A run is architecture-auditable only if:

1. boundary/adapters expose only lawful public structure;
2. CandidateSurface publishes evidence-bearing candidate rows or fails closed;
3. continuation identity is not action identity;
4. branch-internal burden operations and cross-branch relations survive into RCF;
5. CollapseCertificate provides structured earned-collapse reasons;
6. CommitmentSurface expresses earned collapse as native action;
7. no non-CO rescue selector contributes to evidence-bearing behavior;
8. formula ledgers cover every scalar that affects readout.
