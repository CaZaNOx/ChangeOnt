# CandidateSurface

CandidateSurface is the canonical kernel intake surface. It publishes candidate expressions and public signals as evidence-bearing rows. It must not finalize branch identity, invent uniform votes, choose actions, or rescue missing evidence.

Inputs: public candidate expressions, public observations, public effects, masks, task anchor.

Outputs: candidate rows for continuation identity, burden interpretation, relation derivation, RCF, and collapse certification.

Primary docs: `44_CANONICAL_CANDIDATE_SURFACE.md`, `77_PUBLIC_BURDEN_EFFECT_SCHEMA.md`, `78_RUNTIME_SAFETY_AND_FALLBACK_CONTRACT.md`.
