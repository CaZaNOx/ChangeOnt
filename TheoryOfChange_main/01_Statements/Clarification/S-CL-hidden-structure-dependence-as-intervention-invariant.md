# Hidden-Structure Dependence should be measured as a shared intervention-response invariant
## Content
Hidden-Structure Dependence should not be assigned by family intuition or retrospective fitting. It should be measured by a shared intervention-response rule that applies across all admitted problems.

The shared question is:

> How much correct continuation depends on currently hidden or unresolved structure.

## Why this form is needed
If hidden-structure dependence is left as an impressionistic label, then cross-problem placement remains handwavy. The same number on the vector would not mean the same thing across maze, bandit, renewal, games, search, or control.

## Shared measurement idea
A lawful placement should expose whether revealing hidden relevant structure frequently changes which continuation is best. The score should therefore come from hidden-reveal dependence probes.

## Dimensionless readout
A suitable dimensionless readout is: probability that lawful reveal changes the currently best continuation.

What must remain invariant is not the raw unit but the logic:

> stronger expression of the same intervention-response pattern means a more extreme value on the vector.

## Directional law
If a problem deformation changes the task so that the same probe exhibits stronger expression of this pattern, then the vector should move monotonically in the corresponding direction.

## Placement consequence
Higher values should weaken local lock-in and increase information-seeking freedom.

## Misuse warning
It is invalid to assign hidden-structure dependence by family label or by whichever environment later performs best. The score must come from the shared intervention-response rule itself.
