# Regime-shape variation of local unfolding
## Claim (formal)
Local unfolding does not always propagate in the same mode. It can tighten, loosen, spread, concentrate, self-reinforce, reopen, or remain brittle in different ways. This variation in local regime-shape is a real ontological issue of unfolding.

## Philosophical Translation (of formal claim)
The surface on which a local structure continues is not always neutral or fixed. The local mode of unfolding itself can differ.

## Philosophical Justification
[[01_Statements/Definition/S-DF-embedded-stabilized-layers]] shows that local problems arise inside inherited collapses. [[01_Statements/02_Outer_Formation/017_S-DF-bounded-local-unfolding-operative-substrate]] identifies the bounded local unfolding that a structure currently holds. [[01_Statements/Definition/S-DF-self-propagating-selective-retention]] shows that self-propagation is selective and can preserve differently under different conditions. Together these justify a real issue of regime-shape: local unfolding can vary in how rigid, open, spread, or self-reinforcing it is.

## Explanation (informal)
This is the deeper ontological issue behind the current header family. The header is the current representation-layer handle for regime-shape variation; it is not the deepest ontological name for the issue.

## Derivation (Philosophical)
- Embedded stabilized layers bias local unfolding.
- A bounded local substrate inherits these biases and responds to current events.
- Selective self-propagation can preserve and alter differently across contexts.
- Therefore local unfolding can exhibit distinct regime-shapes rather than one fixed neutral surface.

## Derivation (Formal/Logical/Mathematical)
```text
Regime-shape variation names the changing local mode of propagation: tighter/looser, more brittle/more open, more concentrated/more spread, more or less self-reinforcing.
```

## Clarifications / Further Context
- This is deeper than the current header representation.
- The present file does not yet privilege one single runtime taxonomy of regimes.
- It belongs to the canonical philosophical core more strongly than any one current header implementation.
