# 101. RCF Algorithm Comparison and Consciousness Scope

Status: claim-boundary contract; not an implementation claim.  
Binds `_main` file: `TheoryOfChange_main/01_Statements/Clarification/S-CL-rcf-algorithm-comparison-and-consciousness-boundary.md`.

## Minimum RCF distinctness criterion

RCF is not distinct merely because it has branches, uncertainty, or delayed commitment. The minimum diagnostic criterion is:

```text
holding scalar candidate fields fixed,
changing relation topology, burden operations, quotient status, or collapse blockers
must change field/certificate/readout behavior for traceable structural reasons.
```

If this fails, RCF is scalar scoring or known search/planning machinery with CO terminology.

## Known-algorithm comparison obligations

Before novelty claims, compare against:

```text
MCTS / tree search;
dynamic programming;
belief propagation / message passing;
active inference;
options;
successor representations;
state abstraction;
heuristic search;
constraint satisfaction / graph search.
```

The comparison must classify:

```text
shared mechanism;
different interpretation;
actual operational difference;
claimed novelty boundary;
known reduction case.
```

## Consciousness scope

Current kernel work may support the safe bridge:

```text
meaning-like relevance = retained difference that changes continuation burden, salience, admissibility, or collapse-readiness.
```

It does not prove consciousness, AI consciousness, proto-conscious standing, or felt subjectivity.

Open later topics:

```text
subject-pole formation;
felt relevance vs functional relevance;
self-world integration;
graded ethical thresholds;
AI self-report / simulation-vs-modulation tests.
```

## Acceptance rule

No empirical kernel result may be used as a consciousness claim unless a separate consciousness-target theory and test protocol has been written and accepted.
