# Kernel primitives from invariant regimes — bridge from recurrence/invariance structure to operational kernel distinctions
## Claim (formal)
The recurrence/invariance-facing primitive layer is justified when operational distinctions are introduced as disciplined descendants of invariant-regime structure and of the fact that local problems are encountered from within inherited stabilized layers of change.

## Philosophical Translation (of formal claim)
The kernel should not start from a toolbox. It should start from what unfolding itself forces a bounded local structure to notice and carry.

## Philosophical Justification
[[S-DF-invariant-regime]] explains that later kinds differ because change preserves different aspects under different closure conditions. [[S-DR-categories-from-invariant-regimes]] shows how token, pattern, boundary, role, and position arise as regime-families rather than primitive substances. [[S-DF-embedded-stabilized-layers]] adds that local problem spaces are not bare unfolding but inherited collapse layers. Kernel primitives are therefore licensed only as compact operational handles over necessities of unfolding as encountered by bounded embedded structures.

## Explanation (informal)
This file is the bridge from the root recurrence/invariance ontology into the corresponding kernel primitive family. It does not cover every primitive in the repo; bend and gauge are handled by a separate localized-comparability bridge. The primitives here are compact handles over recurrent, invariant-sensitive, and embedding-sensitive structure.

## Derivation (Philosophical)
- Selective recurrence forces temporal and loop-sensitive summaries, otherwise the system cannot tell whether it is stably progressing or merely circling.
- Identity-through-change and invariant regimes force explicit same-enough machinery, giving re-identification and closure/quotient primitives.
- Bounded local embeddedness blocks naive absolute description and motivates relational operator families rather than purely absolute ones.
- Once recurrent structures can be compared and quotient-closed, motif composition becomes a legitimate primitive family rather than ad-hoc pattern mining.
- Self-propagating change under admissible loss motivates a deeper selective-retention economy; MDL is one candidate formalization of that need, but not the need itself.
- Remaining transformation burden motivates remainder/completion language; residuation is one candidate formalization of that need, but not the need itself.
- Order-sensitive composition appears when the project moves from mere counting to path-sensitive and semiring-native combination.

## Derivation (Formal/Logical/Mathematical)
```text
Root bridge:
non-total-erasure -> trace -> selective recurrence -> invariant regime

Embedding bridge:
invariant regime -> inherited stabilized layers -> bounded local problem space

Kernel consequence:
- recurrence across windows -> temporal ops
- trapped recurrence / short cycles -> loopiness (compressed summary)
- admitted continuity under transform -> ReID kernel
- class-forming identity under tolerance -> closure / quotient
- repeatable motif classes under quotient and bounded relational framing -> change ops / changeops core
- self-propagating selective retention under admissible loss -> deeper economy need
- parsimonious recurring structure -> MDL / compressibility (candidate formalization)
- remaining transformation burden -> deeper completion/remainder need
- persistent residual strain under these constraints -> variable birth / order-sensitive control

This bridge does not, by itself, earn bend/gauge primitives; those arise from localized comparability and alignment transport in [[S-DR-kernel-geometric-primitives-from-localized-comparability]].
```

## Clarifications / Further Context
- This file does not claim every current primitive is equally strong.
- It explicitly distinguishes stronger chain-native primitives from weaker imported formal aids.
- It covers the recurrence/invariance family only; bend/gauge belong to the localized-comparability family.
- The bridge justifies the existence of a primitive layer; each primitive file must still justify its own exact role.
