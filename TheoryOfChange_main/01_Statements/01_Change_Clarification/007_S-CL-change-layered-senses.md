# Change has layered senses: root happening, structural unfolding, and later operative articulation must not be silently conflated

## Claim
The family-name “change” covers several layered senses that are all true of the same underlying reality but are not available all at once.

At minimum the route must distinguish:
1. **Root change / happening** — live taking-place, non-flat occurring, unfolding.
2. **Structural change** — overlap, carry, trace, recurrence, admissibility, identity-bearing articulation.
3. **Operative change** — difference, invariance, regimes, representation, collapse.

## Why the distinction matters
If the route uses “change” for all three without discipline, the chain becomes vulnerable to equivocation. The remedy is not to deny that all three are true. The remedy is to state which true aspect is currently in play.

## Why the family remains one
The project is not claiming that these are different primitives. It is claiming that one primitive reality can be described through several increasingly rich articulations.

## Rule for later files
A later file may only use a richer sense of change if it:
- names it,
- shows why it is now available,
- and does not silently treat it as already present at the opening.

## What this establishes
1. The project may keep one broad family-name while still distinguishing layers.
2. Root files are licensed only to use the thinnest sense.
3. Later files must not silently collapse the distinction between root, structural, and operative change.

## What this does not yet establish
It does **not** yet establish a final once-and-for-all lexical formula. It establishes the discipline needed to prevent semantic drift.
