# Process becomes a rival only when it presupposes more than happening

## Claim (formal)
Process becomes a distinct rival to CO only when “process” already presupposes more than sheer happening—for example, a more formed unit, a determinate sequence, a stable process-bearer, or a coherence that has not yet been earned.

## Philosophical Translation (of formal claim)
CO’s pressure against some process views is not a complaint about the word. It is a complaint about the extra conceptual weight sometimes carried by the word. If “process” already means more than happening, then process starts one level later than CO’s primitive.

## Philosophical Justification
The opening secures only happening/modulation. At that stage, it has not yet earned:
- full process units,
- stable relata,
- determinate sequential order,
- or mature organization.

If a process ontology assumes those things as already built into the primitive, then it begins later than CO. In that case, CO may legitimately argue that process is too thick to serve as the thinnest starting point.

## Explanation (informal)
The dispute is therefore conditional:
- if process = happening, no deep dispute;
- if process = happening + more, then the “more” must be examined.

## Derivation (Philosophical)
- The opening secures only root happening.
- Some process concepts carry more structure than that.
- Anything thicker than root happening cannot serve as the thinnest primitive unless that extra structure is independently justified.
- Therefore thicker process notions become real rivals and may be rejected as too early.

## Clarifications / Further Context
The main “more” to watch for is:
- stable process-units,
- pre-given sequence,
- process-bearers,
- or already-formed organization.

The criticism should always target the conceptual surplus, not the label itself.

## Objections addressed

### Objection 1: “Could CO itself not be accused of hidden surplus?”
Yes. That is exactly why the root meaning of change must remain thin and explicitly staged. The present file is only fair if CO subjects itself to the same discipline.

## What this file establishes
This file establishes the exact point at which process becomes a real rival:
- not by name,
- but by conceptual surplus over happening.
