# Minimal trace — selective residue becomes trace when differentiated local shaping can later matter again

## Claim
Selective residue becomes a **minimal trace** when differentiated local shaping does not merely survive once, but can later matter again as shaping. Trace here is therefore not memory-like storage. It is the threshold at which selective residue becomes re-enterable in later continuation.

## Why this threshold matters
Without this threshold, the chain has only one-step selective residue. That is enough for non-flat continuation, but not yet enough for recurrence, reinforcement, or stable identity in change. Minimal trace names the first case where differentiated shaping is not only present, but can later participate again in how change unfolds.

## Argument
1. Selective residue means some local differentiations matter more than others for current continuation.
2. If such differentiated shaping could never matter again beyond its immediate occurrence, then it would remain only one-step selective carry.
3. But recurrence, reinforcement, and stable local formation require that some differentiated shaping be able to re-enter later continuation.
4. Once differentiated local shaping can later matter again as shaping, selective residue has crossed the weakest honest threshold of trace.
5. That threshold is still minimal: it is trace as re-enterable shaping, not trace as memory-object.

## Clarification
This file does **not** claim durable storage, representation, or memory. The point is thinner: some differentiated shaping can be carried forward such that it again influences what continuation is admissible, favored, or inhibited.

## Objection: "Why call this trace rather than mere repeated bias?"
If the same differentiated shaping can later matter again as shaping, then the regime contains more than one-step current-state sensitivity. A differentiated line of influence is re-entering later continuation. The weakest honest label for that is **minimal trace**. Stronger senses of trace belong later, but the minimal threshold is already crossed here.

## What this establishes
1. A first minimal notion of trace is earned: re-enterable differentiated shaping.
2. This is enough for later recurrence and reinforcement talk.
3. It remains thinner than memory, representation, or durable stored mark.

## What this does not yet establish
It does **not** yet establish:
- memory,
- representation,
- long-range identity,
- or durable trace in a stronger sense.
