# Identity Through Change
Overview:
The canonical first-layer route now places **bounded local hold before identity**. Identity is not primitive self-sameness but a later stability claim over a bounded continuing line whose later unfolding remains answerable to a bounded continuation-profile through transformation. The first-layer identity branch now has an explicit order:

1. bounded continuation-profile,
2. identity-through-change,
3. graded similarity,
4. identity-scoped admissibility,
5. derivative thresholding,
6. recognition structure,
7. preserved identity-invariants.

Key idea:
- first there is a bounded local hold,
- then supportable continuation over that hold,
- then a bounded continuation-profile answerable to recurrent unfolding,
- only then can identity be assessed as later same-line stability,
- and only later still can recognition and preserved identity-content be sharpened.
