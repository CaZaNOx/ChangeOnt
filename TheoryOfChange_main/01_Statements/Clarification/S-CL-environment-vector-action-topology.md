# Action topology states how smooth, continuous, or composition-sensitive the action-response landscape is
## Content
Action topology measures how the action surface is structured: whether lawful alternatives are naturally discrete, continuous, smoothly interpolable, or composition-sensitive in a way that changes what candidate separation and local support even mean.

## Why this vector is needed
Some tasks break naive candidate-based placement not because the shared regime law fails, but because the action surface itself is topologically different. Continuous control and hybrid tasks make this explicit.

## Kernel relationship
When action topology is highly continuous or composition-sensitive, candidate rivalry and discriminability must be treated more cautiously, and the kernel should allow broader grouping or local deformation of action identity. When topology is sharply discrete, crisp rivalry fields are more legitimate.

## Placement guidance
Ask: Are the lawful actions naturally discrete units, smooth continua, or compositional transformations? Does tiny movement in action-space preserve nearby meaning, or do legal moves remain fundamentally atomic?

## Directional law
Moving from discrete moves to smooth controls should increase this vector toward continuity-rich regions. Coarsening a continuous control into a rigid discrete set should move it the other way.

## Misuse warning
This vector is global only if it is measured by the same admissible logic across problems. It must not be replaced by family labels or by hidden oracle information. If a problem makes this vector hard to estimate, the right output is a wider region or lower confidence—not a family-specific guess.
