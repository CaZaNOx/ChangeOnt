## Role

P16 is the current execution-level realization of the deeper philosophical need called **remaining transformation burden**.
It estimates how much still has to change before the current local unfolding reaches a more admissible target continuation.

It expresses things like:
- transformation burden still remaining
- reachability deficit
- admissibility deficit
- continuity deficit relative to a learned admissible target region

It is not identical with residuation. Residuation remains an investigatory candidate formalization of the same deeper issue.

## Inputs

Typically sourced from current local comparison and identity signals:
- continuity confidence
- fracture pressure
- identity admissibility
- directional burden
- gauge coherence / frame shift
- optional reward/feedback for target adaptation

## Outputs

Current default fields:
- `transformation_burden`
- `reachability_deficit`
- `admissibility_deficit`
- `continuity_deficit`
- learned target summaries (internal state)

## Current implementation status

Current runtime implementation is a bounded doctrinal realization. It maintains a rolling admissible target profile from recent stable/successful local states, then computes burden as positive deficit from that target region rather than as a raw one-step weighted blend of current signals.
