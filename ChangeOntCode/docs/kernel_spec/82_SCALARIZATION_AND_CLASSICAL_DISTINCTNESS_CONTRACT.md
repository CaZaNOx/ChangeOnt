## 1. Scalarization rule

Scalar fields are allowed only as documented thin collapses of richer continuation structure.

A scalar is acceptable if:

1. its source structure is named;
2. its local operation is named;
3. lost distinctions are identified;
4. lost distinctions are nonoperative for that operation or the scalar is marked provisional;
5. monotonic direction is documented;
6. constants are classified;
7. tests/telemetry show active contribution.

## 3. Grey-pressure boundary

Grey pressure must be traceable to live non-equivalent continuation structure. Generic uncertainty alone is not enough for full grey-preservation claims.

Allowed sources include:

- unresolved burden difference;
- relation topology uncertainty;
- quotient/equivalence uncertainty;
- cancellation/relief uncertainty;
- high consequence span of premature collapse;
- revision cost under wrong collapse.

---

## 4. Minimum RCF distinction test

Hold scalar candidate rows fixed. Change only relation topology.

Expected:

```text
If RCF is relation-field active:
  collapse/readout behavior changes for traceable relation reasons.

If RCF is scalar scoring:
  behavior remains unchanged or changes only through scalar score differences.
```

This is a minimum distinctness criterion, not a full proof of novelty.

---

## 5. What does not count as distinctness

The following are insufficient:

- reward improvement alone;
- deeper branching alone;
- score smoothing alone;
- uncertainty penalty alone;
- adaptive compute alone;
- family-specific action logic;
- post-hoc tuned constants.
