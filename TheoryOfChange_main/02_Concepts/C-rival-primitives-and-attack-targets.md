Overview:
This page fixes the intended meanings of the main rival starting points attacked in the opening so the comparative critique does not drift into strawmen. The goal is not to attack every nearby view, but to state the strongest charitable version relevant to the opening and then specify the exact point of divergence.

## Anti-strawman rule
For each rival start, first ask what the strongest charitable version is. Attack only the point at which that start diverges from change/happening as primitive.

## Definitions-in-use and exact pressure points
### 1. Existence-first / being-first
Strongest charitable version:
- reality is fundamentally being/existence, and becoming is a mode of being.

Exact pressure point:
- CO argues this is weaker where being can still be conceived blankly or statically, while happening still requires explicit ontological work. If being is made rich enough to include happening intrinsically, the dispute narrows and may become largely terminological.

### 2. Substance-first
Strongest charitable version:
- stable identifiable things or units are primary, and changes are modifications of them.

Exact pressure point:
- CO argues that treating stable thinghood as prior starts one level too late, because persistence, boundedness, and identity are precisely what should be derived.

### 3. Passive or merely neutral monism
Strongest charitable version:
- there is one underlying primitive, neither mental nor physical in a one-sided way.

Exact pressure point:
- if the primitive is not already active/happening, the ontology still owes an account of where action, actualization, or occurring comes from. If action is already intrinsic, then the view has moved closer to CO.

### 4. Process (criticized sense)
Strongest charitable version:
- reality is fundamentally processual, dynamic, and non-substantial.

Exact pressure point:
- there is no substantive conflict if “process” means only what CO means by happening/change. The opening critique applies only where process already implies a more formed, coherent, sequenced, or unit-like organization than the root is yet entitled to assume.

### 5. Fixed possibility-space / block / timeless totality
Strongest charitable version:
- all possibilities or world-structure are equally given in a complete totality, while local change is derivative or perspectival.

Exact pressure point:
- CO argues that such views can preserve difference while demoting happening. If actualization is real, then actualization cannot be treated as ontologically cheap relative to the totality.

### 6. Exempt absolute (God-first, ex nihilo, privileged timeless source)
Strongest charitable version:
- a privileged source grounds being, truth, or manifestation more deeply than ordinary change.

Exact pressure point:
- CO argues that if the source must create, reveal, distinguish, decree, or otherwise act, then change is already in play. If the source is instead wholly outside change, its relation to actuality becomes obscure or exception-laden.

## Guidance for use
- Do not attack weaker caricatures when a stronger version is available.
- State explicitly when the dispute collapses into near-equivalence because the rival really means the same primitive by another label.
- State explicitly when the dispute is substantive because the rival adds more than happening at the root, or demotes actualization/happening to a derivative status.

Open items:
- keep refining the strongest non-straw versions of rival positions as the first layer hardens.
