# EE: Selective Retention / Admissible Loss
Current classification: **Investigatory**

Selective-retention/compression candidate retained for comparison, not canonical core doctrine.

## Purpose
EE is the current **non-MDL default** realization of the deeper philosophical need of selective retention under admissible loss and recurrent stability.

It does not treat compression as raw description length. Instead it identifies locally recurrent motifs, builds a bounded closure-stable family over recent unfolding, and measures how much of the current history can be retained under admissible deformation.
