# Theory Completeness Policy

This file records the standard used for the canonical chain.

## Principle
A kernel mapping is only acceptable if the theory chain it depends on is explicit enough that a critical reader can move forward without silent jumps.

## Minimum completeness for canonical files
Each canonical statement in the active root→kernel bridge should include:
- a claim
- a plain-language translation
- a philosophical justification
- an informal explanation
- a philosophical derivation
- a formal/logical derivation where possible
- clarifications
- next steps in chain
