# RCF versus classical scoring — minimum distinction criterion

## Claim
A recursive continuation field is not distinct because it branches, stores candidates, changes scores, or delays commitment. It is CO-distinct only if relation topology, residual burden, quotienting, cancellation, grey preservation, and earned collapse affect behavior independently of one-step scalar candidate ranking.

## Minimum test
Hold scalar candidate scores fixed. Change only relation topology.

If RCF behavior does not change, the field is not doing continuation-field work. It is scalar scoring with CO terminology.

If RCF behavior changes for traceable relation reasons — relief, cancellation, quotient, rivalry, shared evidence, path-density non-equivalence, or grey-preservation pressure — then the field has begun to express a CO-native mechanism.

## What does not suffice
The following do not establish distinctness:

- higher reward alone;
- more branching alone;
- deeper lookahead alone;
- uncertainty penalty alone;
- adaptive computation alone;
- action-score smoothing alone;
- post-hoc family tuning.

## What may suffice
Evidence may support distinctness if:

- branch identity is pressure-signature based;
- relation topology is explicitly published or derived from public facts;
- quotient and cancellation occur in real traces;
- grey preservation follows live-difference criteria;
- earned collapse can be traced to branch-field state;
- changing relation topology changes collapse under fixed scalar rows;
- behavior differs from known algorithms for documented structural reasons, not merely by parameter choices.

## Remaining work
This file gives the minimum criterion. It does not replace detailed comparisons with MCTS, dynamic programming, belief propagation, active inference, options, successor representations, state abstraction, or heuristic search.
