# Clarification — points are local idealizations, not ontic atoms
## Content
Point-language is permitted only as a local idealization over bounded unfolding. It must not be read as evidence that reality is composed of smallest indivisible point-atoms. In the active chain, point/occurrence names a compressed local happening-region under declared resolution.

## Implication
Whenever a later file uses point, state, or location language, it should be interpretable as shorthand for localized occurrence inside bounded change-space rather than literal atomic ontology.
