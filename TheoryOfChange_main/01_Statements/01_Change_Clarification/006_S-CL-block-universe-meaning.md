# A timeless totality can preserve difference while demoting happening to derivative structure

## Claim (formal)
A timeless totality may preserve structural difference, but if all events are equally and tenselessly given, then actual happening is no longer primitive. It becomes derivative, represented, perspectival, or explanatorily demoted.

## Philosophical Translation (of formal claim)
A block picture can keep all the differences while still losing becoming. CO objects not merely to totality, but to any picture in which the occurring-now is no longer fundamental.

## Philosophical Justification
The opening and actualization critique have already established that processive happening matters. A static whole containing all events at once may describe a total structure, but it does not automatically preserve happening as ontologically basic. If all actual differences are already equally present in one timeless completed whole, then becoming has been demoted beneath completeness.

That is the core CO objection: a timeless totality can preserve relation while losing happening as fundamental.

## Strongest rival reply and pressure point
A careful block theorist can say: the sense of passage is simply one ordered feature of certain local states inside the block. That reply is coherent, but it changes the subject. It reclassifies happening as represented structure inside a completed totality rather than preserving happening as ontically basic.

So the criticism of block views is not chiefly logical contradiction. It is explanatory demotion relative to a startup method that takes occurring as minimal datum.

## What this file establishes
This file establishes the exact pressure against block-style rivals:
- they may preserve structure,
- while still weakening becoming by turning it into derivative structure.
