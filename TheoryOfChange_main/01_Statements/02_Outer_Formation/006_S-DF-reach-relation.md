# Bounded bearing relation — carried constraint can still matter for current articulation

## Claim
If present articulation is not self-sealed and carry belongs to overlapping unfolding, then what is not exhausted in the frozen face of the present can still matter for the present articulation. The weakest relational name for that mattering is bounded bearing relation.

## What is genuinely new here
This file does not introduce a dramatic new ontological substance. It adds a relational articulation of already-earned carry: some not-wholly-present differentiation can still bear on what is presently articulated.

## Why this matters against law-style rivals
A rival can say that primitive law explains the next articulation. But for that to mean anything, the present articulation must still constrain admissible continuation. That is exactly the kind of relation this file is trying to name in the weakest possible way. So the relation is not a CO-specific embarrassment; it is part of the burden any structured-update ontology must carry.

## Argument
1. The previous file secures that present articulation is not self-sealed.
2. Carried constraint secures that overlapping unfolding can preserve conditioning across articulation.
3. If such carried conditioning never bore on what is presently articulated, then non-self-closure would remain explanatorily idle.
4. But overlapping carry does bear on current articulation by helping shape what this articulation is rather than some other.
5. The weakest relational name for that mattering is bounded bearing relation.

## What this establishes
1. Beyondness is not wholly inert relative to current articulation.
2. The route may speak of bounded bearing-upon relation.
3. This prepares the ground for local clustering without pretending to have earned a global time-structure.

## What this does not yet establish
It does **not** yet establish:
- geometry,
- metric distance,
- causal law,
- or a finished theory of predecessor structure.
