# Memory minimal witness — prior trace must make a present difference
## Claim (formal)
A minimal memory witness exists when retained prior trace can be reactivated in a way that makes a present difference to the same arising subject. If no carried trace can alter present integration, anticipation, or discrimination, then “memory” has not yet been earned.

## Philosophical Translation (of formal claim)
Memory begins when what was retained before can matter now for the same subject. If the present is always just a fresh isolated flash, then memory is only being named, not derived.

## Philosophical Justification
The outer route has already secured trace-retention: prior change can leave carried conditioning rather than being totally erased. The inner route has now secured an arising subject rather than a mere disconnected pulse. These two achievements make a minimal memory criterion possible.

Memory should not be postulated as a bulk storehouse or as already articulated recollection. The weakest lawful criterion is simpler: some prior retained difference must be able to re-enter present lived organization such that the present for this subject is not the same as it would be under total amnesia. That difference may appear as better discrimination, altered expectation, or changed integration, but the philosophical core is the same: prior trace must still matter now.

## Explanation (informal)
This file gives the minimum test for memory. Memory exists once earlier retained difference can still affect how the current moment is taken up by the same arising subject.

## Derivation (Philosophical)
- Trace-retention already shows that prior change can leave carried marks.
- Subject arisal already shows that there is a continuing inner locus rather than isolated flashes.
- A minimal notion of memory is therefore available when a carried trace can re-enter present organization for that same locus.
- If no such re-entry makes any difference, memory has not yet been earned.

## Derivation (Formal/Logical/Mathematical)
```text
MemoryWitness_min(S) iff there exists retained trace T such that,
for an arising subject S,
present integration with T ≠ present integration without T.

The criterion is existential and weak:
it does not yet require explicit recall, narrative time, or concept use.
```

## Proofs/Corollaries References
- corollary: explicit recollection is a later richer form built on this witness.
- corollary: prediction improvement is one operational signature of the witness, not its whole meaning.

## Clarifications / Further Context
- This file defines the *criterion* for minimal memory, not yet the full mechanism of how traces are stored and reactivated.
- “Difference” here must be ontologically meaningful for the same subject, not merely a third-person bookkeeping difference.
- Operational proxies like contrast statistics or prediction gain may later test this criterion, but should not replace it at the philosophical root.
