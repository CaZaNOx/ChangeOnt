# Strategic Coupling should be measured as a shared intervention-response invariant
## Content
Strategic Coupling should not be assigned by family intuition or retrospective fitting. It should be measured by a shared intervention-response rule that applies across all admitted problems.

The shared question is:

> How much valid continuation depends on other optimizing or reactive agents/processes.

## Why this form is needed
If strategic coupling is left as an impressionistic label, then cross-problem placement remains handwavy. The same number on the vector would not mean the same thing across maze, bandit, renewal, games, search, or control.

## Shared measurement idea
A lawful placement should expose whether best continuation changes because another agent or reactive process responds strategically. The score should therefore come from opponent/reactive response probes.

## Dimensionless readout
A suitable dimensionless readout is: normalized sensitivity of continuation ranking to reactive opponent/process response.

What must remain invariant is not the raw unit but the logic:

> stronger expression of the same intervention-response pattern means a more extreme value on the vector.

## Directional law
If a problem deformation changes the task so that the same probe exhibits stronger expression of this pattern, then the vector should move monotonically in the corresponding direction.

## Placement consequence
Higher values should reduce naive persistence and require more guarded stabilization.

## Misuse warning
It is invalid to assign strategic coupling by family label or by whichever environment later performs best. The score must come from the shared intervention-response rule itself.
