# RelationSurface

RelationSurface is the canonical kernel-side relation derivation surface. It consumes public burden/effect facts and branch-internal burden operations, then derives typed branch relations such as relief, cancellation, shared evidence, equivalence, and strong rivalry.

It must not accept hidden policy, optimal-action labels, baseline values, or action-name hacks as relation evidence.
