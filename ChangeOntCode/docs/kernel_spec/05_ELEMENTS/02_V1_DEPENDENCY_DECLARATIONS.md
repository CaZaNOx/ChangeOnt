# V1 Dependency Declarations

This file declares active dependency roles for the canonical kernel architecture.

## Active runtime surfaces

- `CandidateSurface`: intake publication of candidate expressions and public signals.
- `RelationSurface`: kernel-side derivation of branch relations from public burden/effect facts.
- `RecursiveContinuationField`: field update over continuation branches, burdens, relations, quotient/grey/recursion, and viability.
- `CollapseCertificate`: structured earned-collapse reasons and blockers.
- `CommitmentSurface`: expression of earned collapse as a native action.

## Active core concepts

- remaining transformation burden;
- bend / local deformation;
- gauge / local tolerance;
- temporal retention and identity-through-change;
- closure / quotient;
- change operators;
- thin collapse.

## Dependency rule

Runtime surfaces may instantiate primitives/elements, but they are not themselves deep ontology primitives. A component is active only if it is present in the canonical execution loop and has docs, code, and diagnostics.
