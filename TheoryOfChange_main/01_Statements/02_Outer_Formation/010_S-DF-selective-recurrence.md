# Selective recurrence — repeatable re-entry under bounded retention and filtering

## Claim (formal)
Selective recurrence occurs when a bounded unfolding repeatedly re-enters related forms because some retained aspects continue to matter while others are filtered away.

## Philosophical Translation (of formal claim)
Recurrence is not mere exact repetition. It is the fact that some structures of happening come back again under bounded local conditions, while not everything is preserved. What recurs is therefore selective: some aspects survive re-entry, others wash out.

## Why this claim is needed
If the chain had only carried conditioning and trace, it would still lack a principled distinction between:
- accidental carry-over,
- and stable patterns that return often enough to matter structurally.

Without recurrence, one cannot yet justify later talk of:
- invariant regime,
- identity-through-change,
- or operational attractors.

So the chain needs a node that says more than "something is retained" but less than "there is already an object or law." That node is selective recurrence.

## Philosophical Justification
Trace retention already says prior difference can continue to matter. Bounded local hold says this mattering happens within a finite operative region, not in totality. Once both are granted, a live possibility opens: some retained structures can repeatedly re-enter the unfolding and continue to condition what happens next. Because the hold is bounded and finite, not everything re-enters equally. Some aspects are sustained; others decay or are filtered out. Hence recurrence is selective.

## Explanation (informal)
A storm system, a habit, or a repeated pathway are intuitive later examples, but this file is earlier than those. It says only that the unfolding can revisit related forms in a non-arbitrary way. That re-entry is already enough to ground patterned re-use.

## Derivation (Philosophical)
- Traces can condition later happening.
- A bounded local hold restricts what remains operatively live.
- If a retained pattern repeatedly re-enters the unfolding, then recurrence has occurred.
- Because the live hold is bounded and filtering is unavoidable, recurrence preserves some aspects and drops others.
- Therefore recurrence is selective rather than total.

## Derivation (Formal/Logical/Mathematical)
```text
Let P be a pattern of retained conditioning inside bounded local hold H.
SelectiveRecurrence(P, H) holds if related later unfoldings repeatedly re-enter forms conditioned by P,
while only a subset of prior aspects remains live across those re-entries.
```

## Clarifications / Further Context
- This is earlier than exact sameness.
- It is earlier than numerical iteration or periodic law.
- It is earlier than identity, though it helps make identity possible later.
- It is also earlier than a formal recurrence metric.

## Objection 1: “Isn’t any recurrence already identity?”
No. A pattern can recur selectively without yet licensing the stronger claim that one and the same identity has persisted. Identity requires later work on admissibility, invariants, and recognition. Recurrence is only one precondition.

## Objection 2: “Why must recurrence be selective?”
Because bounded holds and trace filtering already exclude total preservation. If literally everything returned equally, no local filtering or boundedness would remain. Recurrence therefore cannot be total if the earlier chain is correct.

## What this file establishes
This file establishes:
1. repeatable re-entry of retained conditioning,
2. patterned re-use stronger than accidental carry-over,
3. recurrence as necessarily selective, not total.

## What this file does not yet establish
It does **not** yet establish:
- identity,
- full law,
- exact repetition,
- or a completed invariant structure.
