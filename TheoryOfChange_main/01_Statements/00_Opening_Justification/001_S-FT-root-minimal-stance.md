# Root — minimal critical stance for the opening route

## Claim (formal)
A foundational inquiry should begin from the least assumption-rich stance that still permits the inquiry to be carried out coherently.

More precisely: at the opening, one should retain only those commitments whose denial would either:
1. make the act of inquiry impossible to perform coherently, or
2. produce performative instability in the very act of denial.

Everything else is provisionally suspended until it is earned.

## Philosophical Translation (of formal claim)
If the project asks what is most basic, it must not begin by quietly importing what it still intends to justify. So the opening keeps only what cannot be responsibly removed without collapsing the inquiry itself. Richer notions such as world, object, substance, matter, God, law, fixed state-space, or even a thick self are not yet rejected as false; they are simply not yet entitled to function as foundational starting commitments.

## Philosophical Justification
A foundational inquiry is vulnerable to arbitrariness at its beginning. If it starts from familiar metaphysical furniture merely because that furniture is culturally dominant or conceptually comfortable, then the inquiry has already prejudged the result. In that case, later “derivations” will often be little more than unpackings of the starting assumptions.

To avoid that problem, the opening must impose a stricter discipline than ordinary explanatory inquiry. It must ask: what, if anything, remains standing when avoidable commitments are bracketed? This does not mean one must deny all richer commitments. It means one must refuse to *use* them at the root unless their use is already forced.

The present file therefore introduces a methodological admissibility rule for the opening. It is not yet an ontology. It is the discipline by which candidate primitives are allowed or disallowed at the start.

## Explanation (informal)
This file is not trying to prove that change is primitive yet. It is trying to fix the standard by which the opening must proceed. The standard is simple:

- do not import more than the opening needs,
- retain only what survives critical pressure,
- let thicker commitments re-enter only when their absence makes the chain collapse.

That rule is what prevents the opening from smuggling in its winner.

## Derivation (Philosophical)
- A foundational inquiry aims to determine what is most basic.
- If the inquiry begins by assuming rich ontological furniture, it prejudges what is supposed to be determined.
- Therefore the opening must begin from a stance that minimizes imported commitments.
- But the inquiry must still remain performable.
- So the admissible starting set consists of commitments that are unavoidable for the inquiry or whose denial is self-undermining in performance.
- Therefore the opening should begin from the least assumption-rich stance compatible with coherent critical reflection.

## Derivation (Formal/Logical/Mathematical)
```text
Let C be the set of candidate starting commitments.

Retain c ∈ C at the opening only if:
(1) inquiry cannot be coherently carried out without c, or
(2) denying c in the act of inquiry makes that act performatively unstable.

Everything else is provisionally suspended.
```

## Clarifications / Further Context
- This is not skepticism for its own sake. It is a discipline against premature ontological commitment.
- This file does not claim that what is suspended is false. It claims only that it is not yet entitled to serve as a root commitment.
- The opening therefore proceeds by *methodological restraint*, not by dogmatic denial.

## Objections addressed

### Objection 1: “Why privilege this method at all?”
Because the present project is foundational in scope. At that level, arbitrariness at the start is especially damaging. A minimality rule is justified because it minimizes the chance that the supposed primitive is simply inherited from habit.

### Objection 2: “A performative contradiction does not by itself prove a full ontology.”
Correct. The opening does not yet need a full ontology. It needs only a justified foothold—something that cannot be responsibly excluded at the start. That is enough for a disciplined beginning.

### Objection 3: “Is this just ordinary skepticism?”
No. Ordinary skepticism often delights in suspension for its own sake. The present stance uses suspension only as a filter, in order to discover what remains unavoidable and to build from there.

## What this file establishes
This file establishes only the opening discipline:

1. begin thin,
2. retain only what survives critical pressure,
3. postpone richer commitments until they are forced.

That is the methodological root of the opening route.

## What this file does not yet establish
This file does **not** yet establish:
- that change is primitive,
- that experience is the primitive,
- that a subject in a rich sense exists,
- that the world is external,
- that being is more basic than change,
- or that any specific ontology has already won.

It establishes only the rule by which such later claims must be judged at the root.
