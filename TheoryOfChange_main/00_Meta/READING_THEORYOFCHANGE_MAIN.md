# Reading `TheoryOfChange_main`

`TheoryOfChange_main` is now organized first for **human route clarity** and only second for archival statement kind.
The goal is that a serious reader can follow the canonical first-layer path in order, then widen into the broader archive only when needed.

## Canonical first-layer reading order

1. `01_Statements/00_Opening_Justification/`
2. `01_Statements/01_Change_Clarification/`
3. `01_Statements/02_Outer_Formation/`
4. `01_Statements/03_Inner_Development/`

Read the route `README.md` in each folder first. They give the shortest clean path.

## What this path secures

The canonical first-layer route now gives one staged arc:
- the opening justifies why change is the strongest primitive against rival starts and secures explicit global non-cessation with only local regimes of rest or freeze;
- the clarification route fixes what “change” means strongly enough to begin derivation without overloading it and defends in-principle refinability of genuine happening;
- the outer route derives the first world-forming line from shape-sensitive carried constraint through operative relevance and collapse;
- the inner route derives the first lived-development line from subject / awareness / experience through memory, subject-relative loading, and stabilized reusable co-treatment across variation below concept-formation.

- Use `ChangeOntCode/docs/kernel_spec/17_COMPONENT_CLASSIFICATION.md` and `96_CONCEPTUAL_CLOSURE_LEDGER.md` for the current kernel bridge.

## Why the route-first folders exist

Older organization emphasized statement kind (`FoundationalTruth`, `Derivation`, `Clarification`, ...). That preserved archival classification but made the actual argument hard to read in order.

The route-first folders are now the canonical reading path. Statement kind is still preserved in:
- the file name (`S-FT`, `S-DR`, `S-CL`, ...),
- frontmatter (`type:`), and
- tags.

## Rule for future additions

Add a statement to the folder matching its **primary role in the canonical route**, not merely its statement kind.
If a statement smooths a later continuation but is not clearly required for first-layer closure, default to placing it **after** the first-layer boundary rather than silently expanding Layer 1.
